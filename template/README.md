# 网站模板

此目录用于保存后续可复用的网站模板。目前只建立目录说明，尚未放入网站模板。

每个模板使用独立子目录，例如 `template/<template-name>/`，并在自己的 README 中注明：

- 适用场景、技术栈与版本要求
- 本地运行、构建命令和输出目录
- 可替换的文案、主题、页面与配置
- 依赖的环境变量名称和部署要求
- 模板来源与许可

不要保存真实 API key、secret、私钥、服务账号 JSON 或含密钥的 `.env`。示例配置只使用占位值，真实凭据由仓库所有者保存在 GitHub Actions secrets。

Git 不跟踪空目录，因此用本文件保留 `template/` 路径。
